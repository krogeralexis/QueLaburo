# QueLaburo

📦 **Proyecto académico – Archivado**

QueLaburo es una aplicación web desarrollada como **proyecto académico** cuyo objetivo fue construir una plataforma de servicios, donde trabajadores independientes (por ejemplo, plomeros, electricistas, etc.) pudieran publicar sus servicios y los usuarios contratarlos a través de la aplicación.

El proyecto **no se encuentra finalizado** y ha sido **archivado intencionalmente**, ya que el alcance superó el tiempo disponible y actualmente me encuentro enfocado en otros proyectos más alineados con mis objetivos profesionales.

---

## 🎯 Objetivo del proyecto
El objetivo principal fue aplicar conceptos de:
- Desarrollo web full stack
- Arquitectura MVC
- Modelado de bases de datos
- Trabajo en equipo en un entorno académico
- Documentación de Ingeniería de Software (UML)

No fue concebido como un producto comercial ni como una aplicación lista para producción.

---

## 👥 Público objetivo
- Usuarios que desean contratar servicios
- Trabajadores que desean publicar y administrar sus servicios

---

## 🛠 Tecnologías utilizadas
- PHP 8.3
- MySQL
- HTML, CSS y JavaScript
- Arquitectura MVC
- Frontend modular

---

## ✅ Funcionalidades implementadas
Las siguientes funcionalidades se encuentran implementadas y fueron probadas manualmente:

- Página principal
- Registro e inicio de sesión de usuarios
- Hash de contraseñas utilizando `password_hash()` de PHP
- Perfil de usuario
- Publicación de servicios
- Panel de administración de servicios publicados

> Existe un bug conocido al publicar un servicio que redirige al panel de administración. El error fue identificado, pero no corregido debido al archivo del proyecto.

---

## ❌ Funcionalidades pendientes
Por limitaciones de tiempo, quedaron fuera del alcance funcionalidades esenciales como:

- Barra de búsqueda
- Filtros de servicios
- Sistema de mensajería entre usuarios
- Pasarela de pagos
- Endurecimiento de seguridad
- Preparación para producción

El proyecto llegó a estar desplegado en un hosting gratuito como parte de las pruebas finales.

---

## 🧱 Arquitectura
- Patrón MVC
- Separación de responsabilidades entre lógica, vistas y acceso a datos
- Base de datos relacional (estructura diseñada en conjunto con el equipo)

Incluye documentación de Ingeniería de Software con diagramas UML.

---

## 🔐 Consideraciones de seguridad
- Implementación de hash de contraseñas
- No se realizó una auditoría de seguridad completa
- El proyecto **no debe considerarse seguro para producción**
- No se implementaron mecanismos avanzados como rate limiting, validaciones exhaustivas ni protección contra ataques web comunes
